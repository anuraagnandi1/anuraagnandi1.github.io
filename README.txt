SHAWARMAZED WEBSITE — README
=============================

How to open:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, Safari or Firefox.
3. The site is fully responsive and works on desktop + mobile.

What is included:
- Responsive homepage based on the supplied Shawarmazed logo, colours and packaging style
- Interactive Gen-Z inspired hero / ticker / brand sections
- Complete menu with all 14 supplied product names
- Menu filters (Chicken, Paneer, Veg, Bowls, Spicy)
- Add-to-cart, quantity controls and cart drawer
- Demo checkout with customer name, phone, delivery address, notes and payment choice
- Cart persists in the browser using localStorage

IMPORTANT — PRICES:
The user did not provide product prices, so the ₹ prices included are DEMO PLACEHOLDERS.
To edit them, open index.html and update the price values inside window.SHAWARMAZED_PRODUCTS.

IMPORTANT — REAL ONLINE ORDERS:
This package is a front-end prototype. The checkout flow works visually, but it does not send orders to a restaurant or process money.
For a live restaurant site, connect the checkout to:
- a backend/database (Firebase / Supabase / custom API), and
- a payment provider such as Razorpay, Cashfree, Stripe, etc.
